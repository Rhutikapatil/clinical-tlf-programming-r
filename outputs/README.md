# Example Outputs

This directory is reserved for sanitized or synthetic examples of clinical Tables, Listings, and Figures (TLFs).

Original outputs generated from clinical source data are intentionally not included in this public repository because they may contain confidential study information, treatment-specific results, or patient-level summaries.

The R programs in the `R/` directory demonstrate the complete programming workflow used to generate outputs including:

- Demographic and baseline characteristic tables
- Treatment-emergent adverse event tables
- Progression-free survival summaries
- Kaplan-Meier survival figures
- Laboratory shift tables
- Best Overall Response summaries
- Viral load summaries and adjusted mean analyses

Generated outputs based on private clinical data are stored locally and excluded from version control.

This repository focuses on demonstrating the underlying statistical programming, analysis methodology, quality-control procedures, and report-generation workflow.
